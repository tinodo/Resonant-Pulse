# Privacy

Resonant Pulse is designed to work locally without an account, advertising,
analytics or an application cloud service. Projects, preferences and practice
history are stored on the user's computer. Exported files go to user-selected
locations. Audio output is generated on the device.

Input analysis and recording must require explicit activation and visibly
identify when active. A build without those features does not request microphone
access merely because they appear in the long-term design. No captured audio is
uploaded by the application.

Users can remove local data through the application or their Windows user data
folder. Deleting a local project does not erase copies already exported or backed
up elsewhere. Windows, GitHub and Microsoft Store have separate privacy
practices for distribution and platform services.

Before Store submission, publish this policy under an owner-controlled public
URL with an effective date and support/privacy contact. This repository document
is not evidence that a complete Store listing or legal review exists.
